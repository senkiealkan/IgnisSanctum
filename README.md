**Description**: In a realm where the sun has long been extinguished by the "Frost of Oblivion", darkness and silence rule over the ruins of the once-sacred Ignis Sanctum. You are Ignis, the last humanoid Phoenix—a divine entity bound by an eternal cycle of death and rebirth.

**How to use**:
1. Prerequisites
- Unity Hub installed.
- Unity Editor version 6000.1.8f1 or higher.
- .NET / C# support bundled with Unity
- Git (for cloning the repo)
2. Installation
- Clone the repository
- Open Unity Hub > Add > Select the cloned folder.
3. Press Play in the Unity Editor to run the game.
